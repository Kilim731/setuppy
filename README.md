# setuppy
A simple project with main objective of creating python file system easier and quicker on Linux.

Whole project was created using simple bash. It's not a finished project as I'll want to implement different options for directory and file creation.

As for now the whole directory looks like this
```text
name\_chosen\_by\_user
    ├── LICENSE 
    ├── README.md
    ├── src
    │   └── name\_chosen\_by\_user
    │       ├── __init__.py
    │       └── main.py
    └── tests
        ├── test\_core.py
        └── test\_helpers.py
```
